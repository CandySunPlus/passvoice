# 领域文档

本仓库采用单一上下文（`single-context`）。

- `GLOSSARY.md` 位于仓库根目录。探索代码、讨论领域概念或编写规格前，若该文件存在，先阅读相关术语。
- `docs/adr/` 保存架构决策记录。若该目录存在，阅读与当前工作相关的 ADR。

缺少对应文档时继续当前工作。通过 `domain-modeling` 在术语或决策确定后创建或更新文档。

工单标题、重构提案和测试名称使用词汇表中已定义的术语。遇到缺失但需要明确的概念时，交由 `domain-modeling` 处理。提案与已有 ADR 冲突时，指出 ADR 编号并说明重新讨论该决策的理由。
